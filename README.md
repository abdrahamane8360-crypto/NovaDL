# 📥 NovaDL - Effortless Music and Video Downloads

## 🚀 Getting Started

Welcome! NovaDL is a powerful yet simple tool that lets you download music and videos from YouTube, Spotify, and SoundCloud. This guide is designed for absolute beginners - if you can click a button, you can use NovaDL.

## 🎯 What Does NovaDL Do?

NovaDL is a command-line application that downloads media files directly to your computer. Here's what you can do with it:

- **YouTube Videos**: Download any video as MP4 or extract audio as MP3
- **Spotify Songs**: Download tracks, albums, or entire playlists
- **SoundCloud Audio**: Save any track or playlist for offline listening

With **multithreading technology**, NovaDL downloads multiple files at the same time, making it extremely fast - up to 5x quicker than standard downloaders. All you need is the URL of the content you want.

## 🖥️ Step 3: Using NovaDL

Once the command window opens, you'll see a simple interface. Here's how to make your first download:

1. **Type or paste** the URL of the video or song you want to download.
2. **Press Enter** on your keyboard.
3. **Wait** a few seconds. NovaDL will fetch the file and start downloading it.
4. **Check your Downloads folder** (or the folder where you saved NovaDL) for the downloaded file.

**Pro tip**: To download multiple items, just type the first URL, press Enter, and then type the second URL when prompted. NovaDL will queue them and download everything simultaneously using multithreading.

## ⚙️ Important Settings to Know

- **Download Location**: By default, files go to the "Downloads" folder. To change this, type `set folder` followed by the path, like: `set folder D:\MyMusic`
- **Quality Selection**: After pasting a URL, NovaDL will ask if you want video or audio, and which quality. Type `1` for video, `2` for audio, then choose quality (e.g., `best`, `high`, `medium`).
- **Pause/Resume**: Press `P` to pause all downloads and `R` to resume them.

## ❓ Frequently Asked Questions

**Q: The command window closed before I could download. What do I do?**
A: Double-click the NovaDL file again to reopen it. The app only closes when you type "exit" or press Ctrl+C.

**Q: Why is my download slow?**
A: Try closing other programs that use the internet. Also, check your internet speed - NovaDL downloads as fast as your connection allows.

**Q: Can I download an entire playlist?**
A: Yes! Paste the playlist URL and NovaDL will download all videos or songs in that playlist automatically.

**Q: The app says "Python not found." What's this?**
A: NovaDL needs Python installed to run. Go to [python.org](https://www.python.org/downloads/), download the latest Python version, and during installation check the box that says "Add Python to PATH." Then restart NovaDL.

## 🌟 Advanced Features

For users who want more control, NovaDL supports these advanced commands once you're comfortable with the basics:

- Use `format mp3` or `format mp4` to force a specific file type
- Use `limit 10` to only download the first 10 items from a playlist
- Use `proxy address:port` to route downloads through a proxy server

2. **File won't open after download**: Make sure you have a media player like VLC Media Player installed.
3. **App not responding**: Close the window and reopen NovaDL.
